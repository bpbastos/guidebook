# Guia do guidebook

O guidebook gera guias em HTML a partir do Markdown do seu projeto. Ele
monta o guia do usuário e o guia do desenvolvedor.

Os guias abrem com dois cliques, sem servidor e sem internet. O guia
do usuário também pode ser servido com o `guidebook serve`; o do
desenvolvedor fica só no computador de quem tem o repositório.

Se é a primeira vez, siga o tutorial
[Seu primeiro guia](tutorials/01-first-guide.md). Para instalar, veja
[Instalar o guidebook](tasks/00-install.md).
