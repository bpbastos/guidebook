# Glossário

## Diátaxis

Jeito de organizar documentação em quatro tipos: tutorial, tarefa,
referência e explicação.

## Página

Arquivo Markdown dentro de uma das pastas do guia.

## Perfil

Grupo de leitores com a mesma trilha em "Comece por aqui".

## Tarefa

Página que ensina a resolver um problema conhecido, em passos.
